# Plot frequentist methods operating characteristics

This function generates plots for the operating characteristics of
frequentist methods.

## Usage

``` r
power_vs_tie_plots(results_metrics_df, metrics)
```

## Arguments

- results_metrics_df:

  The data frame containing the results and metrics.

- metrics:

  A list of metrics to be plotted.

## Value

None
