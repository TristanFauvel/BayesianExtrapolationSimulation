# Calculate the average type 1 error

This function calculates the average type 1 error based on the
preposterior probability of false positive and the prior probability of
no benefit.

## Usage

``` r
average_tie(prepost_proba_FP, prior_proba_no_benefit)
```

## Arguments

- prepost_proba_FP:

  The preposterior probability of false positive.

- prior_proba_no_benefit:

  The prior probability of no benefit.

## Value

The average type 1 error.
