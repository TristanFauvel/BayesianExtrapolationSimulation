# Plot methods operating characteristics

This function generates plots for the operating characteristics of
different methods.

## Usage

``` r
plot_sweet_spot_width_vs_scenario(sweet_spot_df, sweet_spots_metrics)
```

## Arguments

- sweet_spot_df:

  The data frame containing the results and metrics.

- metrics:

  A list of metrics to be plotted.

## Value

None
