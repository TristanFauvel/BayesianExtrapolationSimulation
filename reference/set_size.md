# Function to set figure dimensions

Function to set figure dimensions

## Usage

``` r
set_size(width, fraction = 1, aspect_ratio = NULL)
```

## Arguments

- width:

  The desired width of the figure (in pts).

- fraction:

  The fraction of the width to use (default is 1).

- aspect_ratio:

  The desired aspect ratio of the figure (default is golden ratio).

## Value

A vector containing the width and height of the figure.
