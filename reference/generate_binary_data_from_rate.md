# Generate binary data from a given rate

This function generates binary data (0s and 1s) based on a given rate
and sample size.

## Usage

``` r
generate_binary_data_from_rate(rate, sample_size)
```

## Arguments

- rate:

  The rate of success (1s) in the generated data

- sample_size:

  The total sample size

## Value

A vector of binary data
