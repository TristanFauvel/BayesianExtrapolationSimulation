# Simulate a Scenario

This function simulates a scenario based on the provided inputs and
returns the results of the simulation.

## Usage

``` r
bayesian_ocs_scenario_simulation(
  scenario,
  simulation_config,
  scenarios_config,
  bayes_filename,
  config_dir,
  case_studies_config_dir
)
```

## Arguments

- scenario:

  The scenario to simulate.

- simulation_config:

  Simulation configuration

- scenarios_config:

  Scenario-generation configuration

- bayes_filename:

  Results were results are stored for Bayesian OCs

- config_dir:

  Configuration files directory

- case_studies_config_dir:

  Case-study configuration directory

## Value

The results of the simulation.
