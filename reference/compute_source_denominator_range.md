# Compute the source denominator range for a given source data, simulation configuration, and case study configuration.

Compute the source denominator range for a given source data, simulation
configuration, and case study configuration.

## Usage

``` r
compute_source_denominator_range(
  source_data,
  scenarios_config,
  case_study_config
)
```

## Arguments

- source_data:

  The source data.

- scenarios_config:

  Configuration for the simulation.

- case_study_config:

  Configuration for the case study.

## Value

A vector representing the source denominator range.
