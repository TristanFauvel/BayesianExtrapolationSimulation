# Compute the Hellinger distance between two normal distributions.

Compute the Hellinger distance between two normal distributions.

## Usage

``` r
hellinger_distance(mu1, sigma1, mu2, sigma2)
```

## Arguments

- mu1:

  Mean of the first normal distribution.

- sigma1:

  Standard deviation of the first normal distribution.

- mu2:

  Mean of the second normal distribution.

- sigma2:

  Standard deviation of the second normal distribution.

## Value

The Hellinger distance between the two normal distributions.
