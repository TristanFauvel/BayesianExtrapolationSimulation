# This function tables for hyperparameters updated using Empirical Bayes across different case studies, methods, and sample sizes.

This function tables for hyperparameters updated using Empirical Bayes
across different case studies, methods, and sample sizes.

## Usage

``` r
table_empirical_bayes_hyperparameters_vs_scenario(results_metrics_df, metrics)
```

## Arguments

- results_metrics_df:

  A data frame containing the results metrics.

- metrics:

  A list or vector of metrics to include in the analysis.

## Value

This function does not return a value. It calls other functions to
create and save multiple tables.
