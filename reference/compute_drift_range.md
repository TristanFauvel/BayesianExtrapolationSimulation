# Compute the drift range for a given simulation and case study configuration.

Compute the drift range for a given simulation and case study
configuration.

## Usage

``` r
compute_drift_range(scenarios_config, case_study_config)
```

## Arguments

- scenarios_config:

  Configuration for the simulation.

- case_study_config:

  Configuration for the case study.

## Value

A vector representing the drift range.
