# Generate simulation scenarios based on the configuration directory.

Generate simulation scenarios based on the configuration directory.

## Usage

``` r
simulation_scenarios(config_dir, scenarios_config, case_studies_config_dir)
```

## Arguments

- config_dir:

  The directory containing the configuration files.

- scenarios_config:

  The simulation configuration file.

- case_studies_config_dir:

  Directory containing the case study YAML files.

## Value

A list of simulation scenarios.
