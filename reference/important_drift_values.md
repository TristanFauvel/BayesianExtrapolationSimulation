# Get important drift values for a given source treatment effect and case study configuration.

Get important drift values for a given source treatment effect and case
study configuration.

## Usage

``` r
important_drift_values(source_treatment_effect, case_study_config)
```

## Arguments

- source_treatment_effect:

  The source treatment effect.

- case_study_config:

  Configuration for the case study.

## Value

A vector of important drift values to consider.
