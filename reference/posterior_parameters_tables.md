# Generate multiple posterior parameter tables

This function generates multiple tables for posterior parameters across
different case studies, methods, and sample sizes.

## Usage

``` r
posterior_parameters_tables(results_metrics_df, metrics)
```

## Arguments

- results_metrics_df:

  A data frame containing the results metrics.

- metrics:

  A list or vector of metrics to include in the analysis.

## Value

This function does not return a value. It calls other functions to
create and save multiple tables.
