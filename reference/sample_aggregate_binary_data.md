# Sample aggregate binary data based on the rate and sample size

This function samples aggregate binary data based on the rate and sample
size.

## Usage

``` r
sample_aggregate_binary_data(rate, n, n_replicates)
```

## Arguments

- rate:

  The rate of success (1s) in the generated data

- n:

  The total sample size

- n_replicates:

  Number of replicates to sample

## Value

A vector of sampled rates
