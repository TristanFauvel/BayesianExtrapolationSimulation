# Calculate the average power

This function calculates the average power based on the preposterior
probability of true positive and the prior probability of no benefit.

## Usage

``` r
average_power(prepost_proba_TP, prior_proba_no_benefit)
```

## Arguments

- prepost_proba_TP:

  The preposterior probability of true positive.

- prior_proba_no_benefit:

  The prior probability of no benefit.

## Value

The average power.
